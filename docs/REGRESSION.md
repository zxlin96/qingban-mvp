# 真机回归清单（发版前逐项过）

> 配合自动化测试 `npm test`（逻辑层）使用，本清单覆盖只能在真机/WebView 上验证的部分。
> 每次发版（版本号变更）前完整过一遍；改动涉及某模块时至少过该模块相关项。

## 1. 启动

- [ ] 冷启动 ≤ 20s 内进入聊天界面，无「启动超时」横幅（启动诊断脚本报错时截图排查）
- [ ] 顶栏版本号显示为本次发版版本（确认新包真的装上了）
- [ ] 二次启动恢复上次对话历史，消息顺序与图片占位正常

## 2. 对话与工具调用

- [ ] 纯文本对话：发送后依次出现「准备中 → 等待响应 Xs」，回复完整不截断
- [ ] 饮食记录：「午餐吃了红烧排骨盖饭」→ AI 调用 write_file 写入 `diet/当天日期.md`，回复含热量估算
- [ ] 体重记录：「体重80公斤」→ BODY_METRICS.md 更新，文件浏览器可见
- [ ] 拍照识图：拍照发送 → 状态条先显示「🔍 识别图片中 Xs」再切「等待响应」，AI 基于识别结果记录饮食；聊天区显示图片缩略图；断网/识别失败时自动回退原图直发（行为同旧版，不阻塞发送）
- [ ] ask_user：让 AI 确认某餐内容 → 底部弹出选项面板，点选后对话继续
- [ ] 通知：让 AI「20分钟后提醒我喝水」→ 到点弹出横幅（+ 系统通知）
- [ ] 工具日志面板：本次会话的 read_file/write_file/checkin_habit 调用记录可见
- [ ] 提示词 v12 行为核对：记饮食/体重/过敏/打卡/推荐/提醒与压缩前行为一致（`npm run prompt:eval` 8/8），纯闲聊不误触发工具

## 3. 习惯打卡

- [ ] 顶栏打卡按钮 → 面板打开，今日习惯卡片/进度条/连续天数正常
- [ ] 快速打卡 +1；带数量打卡（如喝水 0.5L）累加正确
- [ ] 对话中说「刚才跑了30分钟」→ AI 自动 checkin_habit
- [ ] 添加/删除自定义习惯生效

## 4. 跨天后台结算（重点，改过 app.js/chat-manager.js 必测）

- [ ] 手动把系统日期 +1 后重启 APP → 立即进入今日聊天（无阻塞遮罩），顶栏下方出现「🌙 昨日结算中」状态条（呼吸灯动画），输入框立即可用，无「启动超时」横幅
- [ ] 结算进行中发消息 → 对话正常、记在今天日期的文件里，与后台结算互不干扰
- [ ] 点击状态条 → 弹出步骤明细（⏳ 进行中 / ✅ 完成 / ⚠️ 失败），实时刷新
- [ ] 结算完成后：状态条变「✓ 昨日结算完成」约 2.5s 后淡出；chat/昨日.md、habits/昨日.md、21 天习惯总结生成，文件树可见
- [ ] 结算完成时还没聊过天 → 收到完整新一天问候（含昨日总结和今日建议）；已聊过 → 只收到一条「🌅 昨日结算完成」系统提示
- [ ] 凌晨 0-4 点跨天不触发（显示「🌙 还在熬夜」提示），4 点后正常
- [ ] 熬夜时段聊天仍记在昨天日期的文件里
- [ ] 断网状态下跨天（改日期 +1 重启，全程无网）→ 状态条最终变「⚠️ 部分失败，点击查看」且保留可点，聊天不受影响；恢复网络后菜单「刷新习惯总结」可补上 21 天分析（v3.7.0 回归教训：LLM 挂起曾把清单砍断伪装成功）
- [ ] 结算进行中杀掉 APP → 再次启动自动断点续跑（状态条重新出现，已完成步骤显示 ✅ 且直接跳过，只重跑未完成的）
- [ ] **晚间草稿**（22:00 后有对话时打开 App）→ 状态条短暂出现"保存昨日对话摘要"即完成（预生成），次日凌晨/早上结算时该步骤秒过
- [ ] **凌晨后台结算**（不杀后台过夜）→ 早上打开 App 前（4:05 后）结算已在后台完成，聊天区已有完整问候（含昨日总结），无状态条残留
- [ ] 明细弹窗：失败步骤下方灰字/红字显示失败原因；跳过的习惯总结显示"无新数据，已跳过"；全部步骤完成后无"正在…"字样残留
- [ ] 状态条位于聊天区顶部（token 栏上方），高约 28px 细条，不再出现于屏幕中部；结算完成后自动淡出
- [ ] 结算完成后紧接的对话 → AI 能引用昨日总结内容（learned-habits 更新后 KV 前缀缓存已失效，回答不串天）

## 5. 弱网与异常

- [ ] 断网发送 → typing 消失，消息下方出现「🔄 重试」，恢复网络后重试成功
- [ ] 后台切换 1 分钟再回来 → 请求中断时返回部分内容或重试按钮，不白屏
- [ ] 连续快速发送多条消息 → 无串台、无重复回复

## 6. 设置与显示

- [ ] 主题切换（深色/浅色/暖色/晨雾/玻璃/纸感 六主题循环）生效且重启后保留；三新主题下聊天气泡、弹窗面板、菜单、打卡/趋势面板配色协调无漏色
- [ ] 「暗色玻璃」毛玻璃弹窗与「暖纸手账」衬线标题在真机 WebView 渲染正常、滚动不掉帧（低端机重点看）
- [ ] 字体大小调节生效
- [ ] 「查看上下文」能看到系统提示词与消息列表
- [ ] 「刷新习惯总结」触发 21 天分析并完成
- [ ] token 用量条数字合理增长

## 7. 数据安全（阶段二起）

- [ ] 跨天自动快照生成于 .meta/backups/（滚动保留 7 份）
- [ ] 记忆文件被误写后可从快照一键回滚

## 8. 趋势面板（阶段三起）

- [ ] 顶栏「趋势」入口 → 体重折线（近30天）/热量柱状（近7天）/打卡热力图渲染正常，无历史数据时显示空态
- [ ] 老用户升级后历史数据直接出图（无需手动迁移）
- [ ] 图表配色跟随主题切换
- [ ] AI 周报：周日跨天生成 weekly/日期.md，横幅提示可查看，内容含热量/体重/习惯数据

## 9. 系统级通知与主动陪伴（阶段四起）

- [ ] 菜单「提醒设置」→ 首次保存弹出系统通知权限请求，允许后设置生效
- [ ] 关闭全部提醒 → 保存后系统通知栏无轻伴定点通知；重新开启 → 恢复
- [ ] 杀掉 App → 到晨间问候时间（默认 8:00）系统通知栏准时弹出（真机过夜验证）
- [ ] 晨间通知文案含昨日体重变化/打卡次数（有数据时）；点击通知拉起 App 进入聊天页
- [ ] 打卡提醒（默认 12:30 / 20:00）到点弹出，点击通知进入打卡面板
- [ ] 晚间复盘提醒（默认 21:30）到点弹出
- [ ] 修改提醒时间（如晨间改 9:00）保存后按新时间触发
- [ ] AI 发送延迟通知（「30分钟后提醒我」）→ 杀 App 后到点仍弹系统通知；App 在前台时到点弹应用内横幅
- [ ] 周日跨天后 Auto Dream 自动触发生成周报/月报（横幅提示），同日不重复执行
- [ ] 饮食记录后趋势面板热量图正常（record_metrics 双写路径），断网时仍可查看缓存图表
